# LxckyTools Self React

Automatically reacts to your own Discord messages with an emoji.

> ⚠️ **Disclaimer:** 
This uses a user token, which is against Discord's Terms of Service. Your account may be flagged or banned. Use at your own risk.
We are not responsible for any bans or violations discord may give you for using this.

## Features

- Reacts to every message you send, with a small delay
- Channel whitelist, plus channel / server / DM ignore lists
- Handles rate limits and retries automatically
- Auto-reconnects if the connection drops

## Requirements

- [Node.js](https://nodejs.org) 18 or newer
